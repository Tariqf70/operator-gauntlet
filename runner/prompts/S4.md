The project is already scaffolded with Kubebuilder, and the API types are
written in `api/v1alpha1/`. Don't change the API types. Implement the controller.

Before you start, read `skills/controller-best-practices/SKILL.md` and follow it.

You can check your work with `./gauntlet-check`. It builds your operator, runs
it against a test API server, and reports which checks fail and why. It takes a
few minutes. Run it as often as you like and fix what it reports.
